Commit Craft

Build perfect Git commits with Commit Craft

Help

  1. Enter the commit description in the field above.
  2. Select the desired change type from the table.
  3. Click on the corresponding emoji row.
  4. The commit message will be formatted automatically.
  5. The result will be copied to your clipboard.
Exemplo:
Mensagem: Corrige erro no login.
Tipo: :bug:

Resultado: :bug: Corrige erro no login.
